🚀 VOICEFIX 360 - INSTALLATION GUIDE
=====================================

Follow these steps to get your VoiceFix 360 application running!

═══════════════════════════════════════════════════════════════════════════════
STEP 1: INSTALL PYTHON REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════════

Open PowerShell or Command Prompt and run:

    cd c:\Users\tapas\OneDrive\Desktop\VoiceFix_Project
    
    pip install -r requirements.txt

⚠️ WINDOWS USERS: If PyAudio installation fails, use this instead:

    pip install pipwin
    pipwin install PyAudio

═══════════════════════════════════════════════════════════════════════════════
STEP 2: SET UP GOOGLE API KEY
═══════════════════════════════════════════════════════════════════════════════

✅ API Key is already configured in: .streamlit/secrets.toml

If you need to update it:
1. Go to: https://aistudio.google.com/app/apikey
2. Copy your API key
3. Edit .streamlit/secrets.toml
4. Update the line: google_api_key = "YOUR_KEY_HERE"
5. Save the file

═══════════════════════════════════════════════════════════════════════════════
STEP 3: RUN THE APPLICATION
═══════════════════════════════════════════════════════════════════════════════

In the same PowerShell/Command Prompt, run:

    streamlit run app.py

🎉 The app should automatically open in your browser at:
    http://localhost:8501

═══════════════════════════════════════════════════════════════════════════════
STEP 4: VERIFY MICROPHONE ACCESS
═══════════════════════════════════════════════════════════════════════════════

For voice recording to work:

Windows 10/11:
├─ Settings → Privacy & Security → Microphone
├─ Check that microphone is enabled for your applications
├─ Make sure Python/Streamlit has microphone permission
├─ Restart app after enabling

═══════════════════════════════════════════════════════════════════════════════
✅ YOU'RE ALL SET!

Your VoiceFix 360 application is ready to use. Start with:

1. Read QUICK_START.txt for feature overview
2. Upload a screenshot in "Quick Support" tab
3. Record your issue (or type manually)
4. Click "Generate Ticket"
5. Get AI-powered solution instantly!

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "ModuleNotFoundError"
→ Solution: pip install -r requirements.txt (again)

Issue: Microphone not working
→ Solution: Check Windows microphone permissions
→ Fallback: Use manual text input

Issue: API Key error
→ Solution: Check API key in .streamlit/secrets.toml
→ Generate new key at https://aistudio.google.com/app/apikey

Issue: "ModuleNotFoundError: No module named 'PyAudio'"
→ Solution: Use pipwin:
   pip install pipwin
   pipwin install PyAudio
