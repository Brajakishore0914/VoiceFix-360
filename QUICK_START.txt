🚀 5-MINUTE SETUP
=================

1. INSTALL DEPENDENCIES
   ├─ Open Command Prompt/PowerShell
   ├─ Navigate to project folder
   └─ Run: pip install -r requirements.txt

2. CONFIGURE API KEY
   ├─ Go to: https://aistudio.google.com/app/apikey
   ├─ Copy your API key
   ├─ Edit: .streamlit/secrets.toml
   └─ Update: google_api_key = "YOUR_KEY_HERE"

3. LAUNCH APP
   ├─ Run: streamlit run app.py
   ├─ Opens automatically at http://localhost:8501
   └─ You're ready! ✅

🎤 VOICE RECORDING TIPS
========================

For Best Results:

✅ DO:
├─ Speak clearly and naturally
├─ Use a quiet environment
├─ Position microphone 6-12 inches away
├─ Keep sentences short and simple
├─ Speak your native language (no special accent needed)
└─ Test microphone before recording

❌ DON'T:
├─ Whisper or speak too softly
├─ Use in noisy environments
├─ Rush your words
├─ Mix languages in one sentence
├─ Cover the microphone
└─ Record while playing audio

🎙️ Recording Process:
1. Click "🎙️ START REC"
2. System listens for audio
3. Speaks automatically when complete
4. Displays transcript
5. Shows detected language
6. Ready to process

❌ TROUBLESHOOTING QUICK FIXES
===============================

Problem: Microphone not detected
├─ Solution 1: Check Windows Settings → Privacy → Microphone (enabled?)
├─ Solution 2: Try restarting the app
├─ Solution 3: Use manual text input instead
└─ Solution 4: Check if microphone is connected

Problem: "API Quota Exceeded" error
├─ Solution 1: Upgrade at https://aistudio.google.com/app/apikey
├─ Solution 2: Wait 24 hours for reset
└─ Solution 3: Check your current usage

Problem: Speech Recognition Failed
├─ Solution 1: Speak more clearly
├─ Solution 2: Reduce background noise
├─ Solution 3: Keep recording under 15 seconds
└─ Solution 4: Type manually instead

Problem: Translation not working
├─ Solution 1: Check internet connection
├─ Solution 2: Verify API key is set
├─ Solution 3: Try shorter text
└─ Solution 4: Refresh the page (F5)

Problem: App won't start
├─ Solution 1: Check Python version (3.8+)
├─ Solution 2: Reinstall dependencies: pip install -r requirements.txt
├─ Solution 3: Update Streamlit: pip install --upgrade streamlit
└─ Solution 4: Check if port 8501 is available
